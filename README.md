# CecyCafetería

Sitio web escolar de demostración hecho con HTML, CSS y JavaScript. No requiere instalar dependencias ni convertirlo en una aplicación móvil.

## Archivos del proyecto

- `index.html`: estructura y pantallas del sitio.
- `style.css`: estilos y diseño adaptable.
- `script.js`: menú, cuenta demo, registro, carrito y pedidos.
- `img/`: fotografías de productos, categorías y `logo-cecycafeteria.jpg`.

Mantén estos archivos y la carpeta `img` juntos para conservar las rutas de las imágenes y los recursos.

## Abrir el sitio

1. Abre la carpeta del proyecto en el Explorador de archivos.
2. Haz doble clic en `index.html` para abrirlo en tu navegador.
3. También puedes abrir la carpeta con Visual Studio Code y usar una extensión como Live Server.
4. En la pantalla de acceso, usa la cuenta demo:
   - Correo: `demo@cecycafeteria.mx`
   - Contraseña: `demo123`

## Probar las funciones

1. Inicia sesión con la cuenta demo o selecciona **Crear cuenta** para registrar una cuenta temporal.
2. En **Menú**, abre una categoría y revisa los productos y sus imágenes.
3. Escribe el nombre de un producto o categoría en el buscador.
4. Agrega un producto al carrito. Usa `+`, `−` y **Eliminar** para cambiar las cantidades.
5. Confirma un pedido y abre **Ver mi ticket**.
6. En **Mis pedidos**, consulta el pedido y vuelve a abrir su ticket.
7. Cierra sesión y prueba de nuevo el acceso o el registro.

## Alcance de esta demostración

El acceso, el registro y los pedidos son funciones del lado del navegador; no hay servidor, base de datos ni autenticación real. Las cuentas registradas y los pedidos de prueba se guardan solo mientras la página permanece abierta y se pierden al recargarla. No uses contraseñas reales ni publiques información personal.

Para compartir la página mediante un enlace, el siguiente paso puede ser publicarla como sitio estático, por ejemplo con GitHub Pages o Netlify. Al publicarla, conserva `index.html`, `style.css`, `script.js` y toda la carpeta `img`.
